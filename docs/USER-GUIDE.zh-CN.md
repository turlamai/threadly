# Threadly 使用指南

[English](USER-GUIDE.md) · **简体中文**

在原生桌面窗口中阅读和搜索 Racket 社区论坛。

## 当前可用状态

AGPL-3.0 许可的免费社区阅读器，处于维护模式；不要求商业账号，也不销售移动端。

## 平台与安装

桌面维护范围为 macOS、Windows、Linux；移动与手表客户端尚未交付。

从[官方 Releases](https://github.com/turlamai/threadly/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。目前 macOS 包仅使用 ad-hoc 签名，**未获得 Developer ID 签名，也未通过 Apple 公证**；Windows MSI/便携 ZIP 未签名，SmartScreen 可能提示风险。Linux 安装包无需付费开发者账号。应用内更新必须校验 Ed25519 签名及下载文件哈希；不要为安装而关闭系统安全保护。

## 第一次使用

1. 无需登录即可打开最新主题并阅读一篇讨论。
2. 搜索熟悉的短语，打开原论坛链接核对作者与最新内容。
3. 使用登录、回复或 AI 前，核对当前构建是否实际提供该流程，并检查凭据和服务商行为。

## 数据、备份与恢复

论坛始终是内容事实来源。本地缓存可能过期，也不是完整论坛归档。重装前备份个人设置，避免令牌进入共享备份与诊断。

## 联网、密钥与隐私

浏览和搜索会访问公开 Discourse 论坛；登录和回复操作会作用于你的论坛账号。可选 BYOK AI 会把选中文字发送至服务商。遵守限流，未经许可不要发送私密论坛内容。

## 已知限制

阅读、搜索、登录、回帖、点赞、通知与 BYOK AI 均已实现；线程加载失败时读者会给出 Retry（重试）与 Back to list（返回列表），未发送的回复按线程保留为草稿，发出后才清除。各发布渠道的打包安装验收仍未完成——以所用构建的发布说明为准。源帖编辑或删除后，本地缓存可能不同。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/threadly/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
