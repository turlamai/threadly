Announcing Rivet: first-party native desktop apps with a Racket core
alex· #1· 2h 7 ♥

Rivet now ships first-party hosts for all three desktops. The engine stays a plain racket package; each platform gets a thin native shell — SwiftUI, WinUI 3, GTK4 — over the same RVT1 surface.

The interesting constraint is the transport: one binary frame protocol, length-prefixed, no JSON on the wire except where a host genuinely wants it.
