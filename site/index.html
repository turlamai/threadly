在浏览器之外，读 Racket 社区。

AGPL-3.0 许可的免费社区阅读器，处于维护模式；不要求商业账号，也不销售移动端。

Racket 的设计讨论、提案与生态动态都发生在 racket.discourse.group——而浏览器给这些长技术帖套上了一层层外壳。Threadly 用匿名公开的 JSON API 把它们带回原生窗口：论坛原色分类、帖子头像、680px 的阅读栏宽。

为什么需要

🪟

浏览器不是阅读器

每页论坛都在加载一个 Web 应用——脚本、侧栏、层层 chrome。切个窗口，读了一半的长帖就找不到了。

📖

长帖配得上更好的排版

关于类型系统和宏展开器的讨论动辄上百楼：680px 阅读栏宽、帖子头像、论坛原色分类，长文终于有了阅读的样子。

🖥️

桌面端本来就没有

Discourse 只有官方 iOS/Android 应用，桌面用户拿到的只是一个网址。Threadly 补上这块：macOS、Windows、Linux 三个桌面平台都有。

功能

🧵

长帖阅读器

680px 单列阅读栏，论坛 HTML 原样抵达：引用、代码块、表格按论坛语义渲染，不重排。长帖分批加载，滚动位置不丢；本地已读追踪给新帖标「N new」，同坛链接在应用内直开，随时一键跳回网页原帖。0.15.0 的这批阅读打磨先行登陆 macOS，Windows / Linux 平价跟进。

✍️

回复撰写器

Markdown 编辑器贴着讨论写：草稿每敲一键就落盘，切话题、关撰写器都不丢字；Esc 取消、⏎ 发送。回复永远以论坛为准，失败后草稿原样保留、按钮醒来再试。

🔑

登录态，凭据不出本机

登录走 Discourse user API key 流：在浏览器里批准，把论坛给出的代码粘贴回来即完成；凭据只存本机，回帖、点赞、通知不经过任何第三方。论坛当前停发 user API key，登录入口等待论坛政策恢复；匿名阅读不受影响。

🔔

通知

登录后侧栏出现 Notifications 分区：类型图标着 accent 色，未读条目带 ● 前缀，点击直达关联主题；一条通知都没有时，就一行安静的「No notifications.」。

✨

BYOK AI：摘要与翻译

长帖一键 Summarize / Translate，读的是整条线程而不是开头二十楼。Key 完全自带：threadly ai-config 配任意 OpenAI 兼容端点，密钥掩码显示、0600 落盘、只发往所配端点；结果可选中复制，自带免责行提醒回到原帖核对。

👤

匿名优先

匿名即可完整浏览、搜索、阅读。未登录不出现死按钮：写入口要么隐藏、要么一键引导登录——降级是设计出来的，不是残缺。

设计原则

论坛是唯一事实源

Threadly 只缓存、不分叉：编辑、删除、挪版永远以论坛为准，每个帖子都能一键跳回原链。

做好公民

只打公开端点，响应全部落盘缓存并带 TTL，请求带身份标识的 User-Agent，收到 429 老实退避。

凭据留在本机

匿名即可读；登录走 Discourse user API key 流，凭据只存本机——回帖、点赞、通知不经过任何第三方。

长文优先

阅读体验就是产品本身；要移除的恰恰是层层 chrome。Racket 引擎 + 第一方原生 UI，没有 WebView 套壳的网页应用。

三步开始

下载安装

macOS 拖进应用程序文件夹即可——不注册也能读，没有遥测。

浏览最新

侧栏按分类原色列出论坛最新主题，回复、浏览与点赞一目了然；所有响应落盘缓存，重复打开不重复请求。

搜索归档，读长帖

键盘直达全站搜索；读帖视图按阅读顺序呈现整条讨论，随时一键跳回网页原帖。

开始使用

从一次有效使用开始。

AGPL-3.0 许可的免费社区阅读器，处于维护模式；不要求商业账号，也不销售移动端。 桌面维护范围为 macOS、Windows、Linux；移动与手表客户端尚未交付。

无需登录即可打开最新主题并阅读一篇讨论。

搜索熟悉的短语，打开原论坛链接核对作者与最新内容。

需要写操作或 AI 时再配置：登录走论坛授权流；AI 用 threadly ai-config 配自己的端点与密钥，凭据只存本机。

登录动作的真实状态跟随论坛政策：论坛当前停发 user API key，登录、回帖、点赞与通知等待论坛恢复发钥；匿名阅读不受影响。源帖编辑或删除后，本地缓存可能不同。
